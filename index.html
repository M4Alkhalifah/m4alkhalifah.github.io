Majed Assistant

A private, single-user personal assistant. Last updated: 4 October 2026.

What it is

Majed Assistant is a personal tool used only by its owner, Majed. It runs on his own server and lets him manage his own Google Calendar appointments and Google Tasks by sending text or voice messages to a private Telegram bot. It is not offered to the public and nobody else can sign in or use it.

Privacy policy

Data it accesses. With the owner's permission, the app reads and changes events in the owner's Google Calendar and tasks in the owner's Google Tasks. It does this only to carry out the owner's own requests (add, update, complete, delete, list) and to send the owner reminders and daily/weekly summaries in Telegram.

How data is processed. Requests and the relevant calendar/task details are sent to Google's Gemini API so the assistant can understand the request and reply. Replies are delivered through Telegram. Credentials and recent logs are stored only on the owner's own server.

Sharing. The app does not sell, rent or share any data with third parties, does not use it for advertising, and does not run analytics.

Google API data. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion. Calendar events and tasks stay in the owner's Google account. Access can be revoked at any time at myaccount.google.com/permissions; server-side logs are deleted automatically after 14 days.

Contact. Questions about this app can be sent to the support email shown on its Google sign-in screen.
